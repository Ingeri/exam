# Support and community help

Use the channel that best matches your question:

- **API usage and integration:** Start with the [API reference](./docs/API_REFERENCE.md) and [versioned API guide](./api-docs/README.md). For a reproducible API issue, open a GitHub issue using the bug report template.
- **Question formats and grading:** Review [QUESTION_TYPES.md](./docs/QUESTION_TYPES.md). Use the feature request template to propose a new assessment capability or question type.
- **Installation and deployment:** Follow the [deployment guide](./docs/DEPLOYMENT.md) and the setup section in the [README](./README.md).
- **Code contributions:** Read [CONTRIBUTING.md](./CONTRIBUTING.md) and submit a pull request with the repository template.
- **Private product or organization questions:** Use the contact channel published on [ingeritech.com](https://ingeritech.com).
- **Security vulnerabilities:** Do not report them in public issues. Follow [SECURITY.md](./SECURITY.md) and use the private contact channel published on [ingeritech.com](https://ingeritech.com).

When asking for help, include the route, method, sanitized request shape, response status, and relevant software versions. Use test data and redact bearer tokens, exam keys, student names and email addresses, grades, and database connection strings. Do not attach production database dumps or answer keys.
